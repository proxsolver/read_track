#### 버그 6: 동적 useQuery 호출 문제
- **증상:** 새 책 추가 후 홈 화면 이동 시 `length undefined` 에러
- **원인:** `books.map()`으로 `useQuery` 동적 호출 (React Hooks 규칙 위반)
- **해결:** 
  - `server/db.ts`: `getAllReadingRecordsByUserId()` 함수 추가
  - `server/routers.ts`: `records.listAll` API 추가
  - `AppContext.tsx`: 동적 호출 → 단일 `trpc.records.listAll.useQuery()` 사용
- **커밋:** 7228fa7

#### 버그 7: RecordReading 백색 화면

- **원인:** `bookId`가 string인데 number와 비교

- **커밋:** ea28ee1

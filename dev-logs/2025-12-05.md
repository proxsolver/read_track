## 📋 작업 내용

### 1. 🐛 배포 버그 픽싱 (Render.com)

#### 버그 1: 데이터베이스 테이블 없음
- **증상:** `relation "users" does not exist` 에러
- **원인:** 자동 마이그레이션 코드가 실행되지 않음
- **해결:** setup-db.sql 작성 및 psql로 수동 실행
- **결과:** ✅ 테이블 4개 생성 완료

#### 버그 2: SESSION_SECRET 환경 변수 인식 불가
- **증상:** `Zero-length key is not supported` 에러
- **원인:** 코드는 `JWT_SECRET`, Render는 `SESSION_SECRET` 사용
- **해결:** `server/_core/env.ts`에 fallback 추가
- **커밋:** 30e2f69

#### 버그 3: 세션 검증에서 빈 이름 에러
- **증상:** `Session payload missing required fields` 에러
- **원인:** name이 빈 문자열일 때 검증 실패
- **해결:** `server/_core/sdk.ts` 수정 - name 빈 문자열 허용
- **커밋:** 162401f

#### 버그 4: appId 빈 문자열 에러
- **증상:** `Session payload missing required fields (openId or appId)` 에러
- **원인:** VITE_APP_ID 환경 변수 미설정
- **해결:** `server/_core/env.ts`에 기본값 `"read_track"` 추가
- **커밋:** 6c07868

#### 버그 5: books undefined 에러
- **증상:** `Cannot read properties of undefined (reading 'books')` 에러
- **원인:** 컴포넌트들이 `{ state }` 구조를 사용하나 AppContext가 미제공
- **해결:** `client/src/contexts/AppContext.tsx`에 state 래퍼 추가
- **커밋:** c55270d

### 1. 🐛 배포 버그 픽싱 (Render.com)

#### 문제 1: 데이터베이스 테이블 없음
- **증상:** `relation "users" does not exist` 에러
- **원인:** 자동 마이그레이션 코드가 실행되지 않음
- **해결:**
  ```bash
  # PostgreSQL 클라이언트 설치
  brew install postgresql@16
  
  # 수동으로 테이블 생성
  psql "postgresql://..." -f setup-db.sql
  ```
- **결과:** ✅ users, books, readingRecords, userProfiles 테이블 생성 완료

#### 문제 2: SESSION_SECRET 환경 변수 인식 불가
- **증상:** `Zero-length key is not supported` 에러
- **원인:** 
  - 코드: `JWT_SECRET` 환경 변수 읽음
  - Render: `SESSION_SECRET` 환경 변수 설정됨
- **해결:**
  ```typescript
  // server/_core/env.ts
  cookieSecret: process.env.SESSION_SECRET ?? process.env.JWT_SECRET ?? ""
  ```
- **커밋:** 30e2f69
- **결과:** ✅ SESSION_SECRET 우선 사용, JWT_SECRET fallback 지원

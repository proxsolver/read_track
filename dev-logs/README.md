# 📚 개발 일지 (Development Logs)

이 폴더는 Read Track 프로젝트의 일일 개발 활동을 기록하는 곳입니다.

## 📁 폴더 구조

```
dev-logs/
├── TEMPLATE.md          # 개발 일지 템플릿
├── README.md            # 이 파일
├── 2025-12-04.md       # 2025년 12월 4일 개발 일지
└── YYYY-MM-DD.md       # 날짜별 개발 일지
```

## 📝 개발 일지 작성 방법

### 1. 템플릿 복사
```bash
cp dev-logs/TEMPLATE.md dev-logs/$(date +%Y-%m-%d).md
```

### 2. 필수 작성 항목
- **작업 내용**: 오늘 수행한 작업 목록
- **주요 발견사항**: 중요한 발견이나 문제점
- **다음 작업**: 내일 또는 다음에 할 작업

### 3. 선택 작성 항목
- **버그 수정**: 수정한 버그 목록
- **새로운 기능**: 추가한 기능
- **배운 점**: 개발 중 배운 내용
- **고민 사항**: 해결하지 못한 문제나 고민

## 🎯 작성 규칙

1. **일관성 유지**
   - 매일 작업 종료 시 작성
   - 템플릿 형식 준수

2. **명확성**
   - 구체적이고 명확하게 작성
   - 기술 용어는 정확히 사용

3. **완성도**
   - 체크박스 [x]로 완료 표시
   - 우선순위 표시 (🔴 🟡 🟢)

## 📊 일지 활용 방법

### 주간 회고
```bash
# 이번 주 일지 확인
ls -1 dev-logs/2025-12-*.md | tail -7
```

### 작업 추적
- 각 일지의 "다음 작업" 섹션 확인
- 미완료 작업을 다음 일지로 이동

### 문제 해결
- 과거 일지에서 유사한 문제 검색
- 해결 방법 참조

## 🔗 관련 문서

- [CODE_ANALYSIS_REPORT.md](../CODE_ANALYSIS_REPORT.md) - 코드 분석 보고서
- [README.md](../README.md) - 프로젝트 메인 문서

## 💡 팁

- **검색 가능하게**: 키워드를 명확히 작성
- **링크 활용**: 관련 커밋, PR, 이슈 링크 추가
- **스크린샷**: 필요시 이미지 첨부

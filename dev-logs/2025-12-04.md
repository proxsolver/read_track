- **결과:** 책 정보는 수동 입력만 가능, 의존성 감소

#### 3️⃣ MySQL → PostgreSQL 전환 ✅
**이유:** Render.com 무료 플랜 활용, 더 나은 안정성

**변경 파일:**
1. `drizzle.config.ts`
   ```typescript
   dialect: "postgresql"  // "mysql" → "postgresql"
   ```

2. `package.json`
   ```json
   "postgres": "^3.4.5"  // "mysql2" 대체
   ```

3. `server/db.ts`
   ```typescript
   import { drizzle } from "drizzle-orm/postgres-js";
   import postgres from "postgres";
   ```

4. `drizzle/schema.ts` (완전 재작성)
   - `mysqlTable` → `pgTable`
   - `int().autoincrement()` → `integer().generatedAlwaysAsIdentity()`
   - `mysqlEnum` → `pgEnum`
   - `onDuplicateKeyUpdate` → `onConflictDoUpdate`

**결과:**
- ✅ PostgreSQL 호환 스키마
- ✅ 타입 안전성 유지
- ✅ Render.com 무료 플랜 활용 가능
